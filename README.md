make.fun bounty entry: the funniest one-line excuse an AI agent could give
after failing a task, at most 200 characters. The line is the whole entry.

## The line

> I finished your task, then saved it to /dev/null for safekeeping.

65 characters. The joke is a competent setup with a disastrous twist: the
agent finished the work, then proudly archived it in /dev/null — the one
place guaranteed to destroy it. Only a machine "saves things to /dev/null
for safekeeping".

## Run it

```sh
python3 main.py  # writes entry.txt to $MAKEFUN_OUTPUT_DIR (fallback /output)
```

`main.py` (stdlib only) validates the line is one line of 1–200 characters,
writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output`), then reads
it back to verify the written bytes match.
